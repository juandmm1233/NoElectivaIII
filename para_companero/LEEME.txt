Entrenamiento ligero - plantas medicinales
==========================================

Esta carpeta es la copia del proyecto para entrenar en casa el modelo LIGERO.

Modelo de esta copia: MobileNetV2 (pesos de ImageNet).
El otro integrante entrena en el otro PC un modelo de esta lista:
ResNet50, DenseNet121, ConvNeXt o EfficientNet.
Los dos usan la misma carpeta dataset/ (57 especies, split 70/15/15, semilla 42).
No vuelvas a partir las imagenes: si cambias el split, la comparacion deja de ser valida.

El dataset ya viene incluido:
  dataset/train   3408 imagenes
  dataset/val      734 imagenes
  dataset/test     761 imagenes

No hace falta cuenta de Kaggle ni GPU. En CPU el entrenamiento completo
suele tardar entre 2 y 4 horas. Puedes dejar el PC encendido y volver despues.


1. Requisitos
-------------
- Windows 10 u 11
- Python 3.10 o 3.11 (64 bits). Python 3.12 puede fallar al instalar TensorFlow.
  Descargalo de https://www.python.org/downloads/ y marca "Add python.exe to PATH".


2. Instalacion (una sola vez)
-----------------------------
Abre PowerShell en ESTA carpeta (la que contiene entrenar_ligero.py) y ejecuta:

    python -m venv .venv
    .venv\Scripts\activate
    python -m pip install --upgrade pip
    pip install -r requirements.txt

La primera vez TensorFlow descarga los pesos de ImageNet (unos 10 MB).


3. Comprobar que el PC puede entrenar
--------------------------------------
    python entrenar_ligero.py --prueba

Eso corre 1 epoca por fase. Sirve para ver que no hay errores.
Esas metricas NO se usan en el informe.


4. Entrenamiento para el trabajo
--------------------------------
    python entrenar_ligero.py

Si el PC se queda sin memoria, corta con Ctrl+C y relanza asi:

    python entrenar_ligero.py --batch 8

Al terminar, en la carpeta resultados/ quedan:

    modelo_mobilenetv2.h5          modelo entrenado
    metricas_mobilenetv2.json      accuracy, top-3, tiempo, parametros, tamano
    reporte_mobilenetv2.txt        precision y recall por especie
    curvas_mobilenetv2.png         accuracy y loss de las dos fases
    matriz_mobilenetv2.png         matriz de confusion
    clases.json                    orden de las 57 clases

Devuelve al grupo la carpeta resultados/ completa.
El numero que hay que comparar es accuracy_test dentro de metricas_mobilenetv2.json.


5. Como se entrena (para el informe)
------------------------------------
- Entrada 224x224.
- Augmentacion solo en entrenamiento: giros, rotacion, zoom, desplazamiento, contraste y brillo.
- Cabeza: GlobalAveragePooling + Dropout 0.4 + capa densa softmax (57 clases).
- Fase 1: MobileNetV2 congelado, Adam 1e-3, hasta 20 epocas.
- Fase 2: se descongelan las ultimas 40 capas, Adam 1e-5, hasta 15 epocas.
- Early stopping sobre val_accuracy (paciencia 5) y reduce el learning rate si val_loss se estanca.
- Metrica principal: accuracy en test. Tambien se guarda top-3, porque hay 57 clases parecidas.

fichas_medicinales.csv es la tabla de usos. El modelo solo identifica la especie;
no predice para que se usa la planta.
